## 📖 这是什么

**Kins Vault** 是我日常思考与总结的公开存档。

平时遇到一个问题、想通一个道理、整理出一套方法，我会顺手把它整理成一个**单文件 HTML**：不用装环境、不用跑构建，双击就能在浏览器里打开，能直接发给别人看。

这里放的就是这些页面。它们大多不是什么严肃的项目，而是**思考的副产品**——可能是某个概念的图解、一次踩坑的记录、一套小工具，或者只是一张用来理清思路的图。

## 🚀 如何使用

**方式一：直接看** — 进入对应文件夹，点击任意 `.html` 文件即可在浏览器中打开（GitHub 会提供在线预览）。

**方式二：拉到本地** — 想离线看或者自己改着玩：

```bash
git clone https://github.com/kinsluck/kins-vault.git
cd kins-vault
# 双击任意 .html 文件即可
```

**目录结构**（随着收录内容增长）：

```
kins-vault/
├── README.md
├── LICENSE
├── notes/          # 思考笔记：概念图解、方法论、认知总结
├── tools/          # 小工具：能直接用的单页应用
├── visual/         # 可视化：数据图表、流程/结构图
└── experiments/    # 实验场：一时兴起写的东西
```

> 📌 目前仓库刚开张，目录会随着内容逐步填满。没看到空文件夹是正常的 👀

## ✨ 收录范围

|  ✅ 会放进来 |  ❌ 不会放进来 |
| :--- | :--- |
| 想清楚一件事后的**总结与图解** | 未整理的草稿与半成品 |
| 能独立运行的**单文件 HTML** | 需要复杂构建/依赖的项目 |
| 有复用价值的**小工具** | 纯个人隐私内容 |
| 踩坑记录与**最佳实践** | 从别处搬运的内容 |

**技术取向**：优先单文件、零依赖、开箱即用。能用原生 HTML / CSS / JS 解决就不引框架。
