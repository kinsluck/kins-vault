转换规则与依据（点开查看）
  • 大写数字用 零壹贰叁肆伍陆柒捌玖，单位用 拾佰仟万亿，不得用简化字或自造字。
  • 大写金额前应标明“人民币”，币种与金额之间不留空白。
  • 金额到“元”或“角”为止的，在“元”或“角”后写整（或正）；有“分”的，“分”后不写整。
  • 数字中间有 0 时写“零”；连续多个 0 只写一个“零”。
  • 元位是 0、角位不是 0 时，可写一个“零”也可不写（页面提供开关）。
  • 角位是 0、分位不是 0 时，“元”后应写“零”，如 ¥1409.05 → 人民币壹仟肆佰零玖元零伍分。

依据：财政部《会计基础工作规范》第五十二条；《正确填写票据和结算凭证的基本规定》。
示例：¥1409.50 → 人民币壹仟肆佰零玖元伍角整；¥6007.14 → 人民币陆仟零柒元壹角肆分；¥107000.53 → 人民币壹拾万柒仟元伍角叁分。
