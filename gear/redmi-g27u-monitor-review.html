27 英寸 Fast IPS（BOE NF7） 4K 160Hz / 1080P 320Hz 双模 DP 2.1 54Gbps + HDMI 2.1 HDR400 TUV 硬件低蓝光
一句话结论：同价位（1500 元档）观感与调校最强的一台 LCD 游戏显示器—— 默认模式的观感、色温、色准三项把同价位产品「断崖式超越」；代价是均匀性/可视角一般， 以及 HDR 暗部调校有明确缺陷（UP 主已反馈，小米回复「很快修复」）。

产品定位

  • 面板：BOE NF7（27 英寸 Fast IPS）。UP 主特别注明——不是常见的友达 7.6 双模屏。
  • 双模高刷：4K 160Hz ↔ 1080P 320Hz。4K 模式擅长单机大作，1080P 模式专攻 FPS。
  • 接口：54 Gbps DP 2.1 + HDMI 2.1；DP 口可在不触发 DSC 的情况下实现秒切屏。
源素材存在一处自相矛盾：视频 01:40 的「双模配置」卡片写的是 「4K 160Hz / 1080P 360Hz」，而官方产品页、视频标题与实测表格用的都是 320Hz。本文以 320Hz 为准（实测表也按 320Hz 记录），360Hz 疑为作者配图笔误。

优点（UP 主排序）

★ 观感调色无敌 —— 核心卖点

开机即感知的差距。UP 主原话：「市面上没有任何一台 LCD 游戏显示器能和 G27U 比观感。」三点支撑：

  • 白点极准：「白色白得纯净，一点也不偏，符合我对『白』的认知」；对比其他显示器「明明是偏黄或偏蓝，却偏要跟你说这是白」。
  • 通透、雾面感轻：「有点 Nano IPS 的感觉」。
  • 硬件低蓝光还能做好色（全文最反直觉的一点）：他看到 G27U 时的第一反应是 「软件低蓝光」，因为「只有软件低蓝光才能做出完美的白色」，而他见过的硬件低蓝光显示器都会偏黄/偏绿； 然而测试发现 G27U 竟然是硬件低蓝光显示器（短波蓝光 37%）—— 「我从未见过硬件低蓝光显示器还能把色调得如此好的。仅凭这一点，G27U 就有绝对的不可替代性，就值得无脑入手。」

4K 160Hz / 1080P 320Hz，4K 模式擅长单机大作、1080P 模式专攻 FPS，适合所有类型游戏。

6、模具和接口出色

颜值很高，同价位中「算数一数二的水平」；接口「良心到家了」——54 Gbps DP 2.1 + HDMI 2.1。

缺点（UP 主称「几个致命缺陷」）

1、均匀性和可视角较差

  • 25 区域测试中，7 个区域色度不均超过 4，「人眼能看出屏幕左右两边的颜色有点不一样」。
  • 可视角不好：和此前对比过的 2 台雷神显示器放在一起能明显看出差距；可视角不足会进一步放大均匀性问题，「人眼看起来会有一点阴阳屏的感觉」。
  • 程度：「好在不算很严重，勉强能忍」。

2、HDR 调校较差（最实质的问题）

  • 从 EOTF 看，低亮度部分直接是一条横线、没有区分；
  • 导致「暗部细节大量丢失，所以黑阶测试里一个黑阶都看不到，暗部细节极差」；
  • UP 主已反馈小米，视频剪辑时收到官方人员回复：暗部细节问题很快会修复。

3、SDR 与 HDR 色温割裂

默认模式 7110 K（7000–7100K 区间），HDR 自动 6381–6454 K（6300–6400K 区间）， 相差约 700 K，「所以从 SDR 到 HDR 会有观感上的割裂」。

4、面板-背光适配性差（亮度损失）

OSD 拉满对比度后，白场亮度从 487 → 555 nits，差值 68 nits，评价「较差」 （参考标准：差值 <20 nits 优秀，30–50 一般，50–80 较差，80 以上极差）。

「如果把这部分损失的亮度加回来，估计对比度会增加至少 10%，观感也会更好。」

Gamma 补充说明（画面文字）： Gamma 调得还不错，整体偏离不多。可惜没有做 sRGB 模式和其他模式的区分，似乎所有模式都是朝着 2.2 去调的。 对日常使用和游戏基本没影响。但用来做设计的话可能会有点影响，因为 sRGB 模式的低灰阶部分会轻微偏暗。

购买建议

值得买

  • 「买来就能用、不用校色」的游戏玩家：默认模式观感与色准是同价位天花板，省去调校成本。
  • 单机 + FPS 通吃：4K160 与 1080P320 一键切换，一个档位从头用到尾。
  • 关心护眼又不想牺牲色彩：硬件低蓝光 + 94% P3，这个组合在同价位少见。

需要斟酌

  • 设计/修图为主：sRGB 模式低灰阶轻微偏暗、Gamma 未分模式，加上均匀性一般（25 区域中 7 个区域色度偏差超标），能用但不理想——UP 主的建议也是「小米赶紧做专业设计显示器」。
  • 重度影音用户：HDR 暗部细节目前有明显缺陷，建议等固件修复后再评估（小米已回复会修）。
如果成本和售价能再增加一点、改善均匀性，并通过更新固件调好 HDR，「那 G27U 就是真正意义上的完美了」。
