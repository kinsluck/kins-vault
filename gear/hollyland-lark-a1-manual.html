1快速上手

三步开录。TX 与 RX 出厂已配对，日常使用直接从充电盒取出即可。

STEP 1
充电
TX 放入充电盒，USB-C 线连接充电盒与电源；也可将 TX 放入一拖二充电座单独充电。取出即自动开机，放回即自动关机。
STEP 2
连接
按手机接口选择 RX：Type-C 插 Type-C 口，Lightning 插 Lightning 口。手机会自动识别为音频输入设备，无需手动选择。
STEP 3
佩戴与开录
TX 磁吸到磁吸片别在衣领（麦克风孔朝上），有风环境装上防风毛衣。TX 按键三击即可远程开始 / 停止录制。
边充边用：RX 侧边设有 Type-C 供电口，手机电量低时，可从 RX 侧给手机反向供电，满足长时间连续拍摄或直播。该机型通过 Apple 官方 MFi 认证。
麦克风孔方向：佩戴时务必让 TX 顶部收音孔朝上，这是获得最佳拾音效果的前提。官方资料中把这一点单独列为「穿戴」章节的注意事项。

5App 功能设置

使用 LarkSound App（国行渠道软件名为 MOMA SOUND）即可完成全部功能配置。需先将手机版 RX 连接手机，再在 App 中设置。

下载与系统要求：App 可在小米、华为、Apple 应用商店及 Google Play 搜索 LarkSound 下载，也可用纸质说明书上的二维码扫码。要求 iOS 12.0 或更高、Android 8.0 或更高版本。

降噪档位

档位降噪量官方建议场景
弱（Weak）10dB以低频噪声为主的环境（空调、电流声、轻微车流）
中（Medium）15dB中等噪声环境（家庭办公、轻微环境杂音）
强（Strong）20dB多数室外环境 默认值

开启降噪会缩短 TX 单次续航（开启约 6.5 小时，关闭约 9 小时），并可通过 TX / RX 单击快速开关。

6配对与连接

TX 与 RX 出厂前已预配对，正常使用无需重复配对。以下仅在换机、连不上或混用多支 TX 时需要。

  1. RX 进入配对：长按 RX 配对按键 3 秒，指示灯蓝色快闪，表示进入配对状态。
  2. TX 进入配对：TX 处于关机状态下，长按开机按键 6 秒，指示灯蓝色快闪，进入配对状态。
  3. 完成配对：两端指示灯由快闪变为蓝色常亮即连接成功。
重要限制：TX 处于已连接状态时无法进入配对模式；两支 TX 可分别单独与 RX 配对。配对前建议先重置设备：TX 放回充电盒关机，RX 拔出后重新插入手机。

连接方式

  • Type-C 版 RX 插入手机 Type-C（USB-C）接口。
  • Lightning 版 RX 插入手机 / 平板 Lightning 接口。
  • 插入后手机自动识别为音频输入设备，无需安装 App 或额外授权即可开始录音。
  • 手机电量低时，可由 RX 侧边 Type-C 口反向为手机供电，实现边充边用。

佩戴

  • TX 通过磁吸片吸附在衣领等位置，麦克风孔朝上。
  • 有风环境（户外、车流、空调出风口）装上 TX 防风毛衣，降低风噪。
  • TX 仅 8g、厚度约 0.9cm，即使薄 T 恤也不会外翻垂坠。

7充电与续航

两种充电方式：充电盒（随盒附带）与一拖二充电座（部分版本附带），均使用 USB-C 线供电。

方式连接作用范围
充电盒USB-C 线连接充电盒与电源为充电盒与盒内设备整体供电
一拖二充电座USB-C 线连接充电座与电源为充电座上的 TX 充电
  • TX 充电时长 < 1.5 小时，充电盒充电时长 < 1.5 小时。
  • 充电盒满电可同时给两支 TX 充电 > 2 次。
  • 充电环境温度 0 ~ 45℃，超出范围可能无法正常充电。
  • TX 放入充电盒即自动开机充电，放回即自动关机，因此长期不用时请确保电量在 50% 左右再收纳，以延长电池寿命。
  • 清洁时用柔软干燥的布擦拭，避免液体与磨料清洁剂；定期清洁充电触点，防止氧化导致充不进电。

8固件更新

  1. 将 TX 通过手机版 RX 连接至手机，打开 LarkSound / MOMA SOUND App。
  2. 进入设置图标，查看版本信息与升级选项，点击固件更新。
  3. 更新过程中 RX 指示灯为粉色常亮，TX1 / TX2 同步显示。
  4. 更新成功后设备自动重启。
注意：更新过程中切勿拔掉 RX。若更新失败，App 会弹出错误提示，此时将 TX 放回充电盒后重新尝试。

9常见问题

如何手动配对？
  1. RX 长按配对按键 3 秒，指示灯快闪进入配对状态。
  2. TX 在关机状态下长按开机按键 6 秒，指示灯快闪进入配对状态。
  3. 两个 TX 可单独与 RX 进行配对。

补充：TX 已连接时无法进入配对；设备出厂前已预配对。TX 需蓝灯快闪才处于配对模式。

如何开启静音？

LARK A1 支持 TX 端和 RX 端开启静音功能：

  • TX 端：连续双击该麦克风按键，对该支麦克风静音。
  • RX 端：连续双击按键静音 TX1，连续三击按键静音 TX2。

静音时该设备指示灯为红色常亮。

MIC 识别功能是什么？

该功能选项开启后，TX1 指示灯颜色为紫色，TX2 指示灯颜色为黄色，用于双麦场景下区分两支麦克风的身份。

注：降噪开启时，会优先显示降噪模式的绿灯；当指示灯开关选择「关」时，TX 上指示灯会关闭。

TX 指示灯不亮、没反应怎么办？

这是正常功能设计，不是故障。LARK A1 支持指示灯开关功能：在 MOMA SOUND App 内关闭指示灯开关后，TX 上的指示灯会显示熄灭状态。需要常亮时在 App 内重新打开即可。

没有声音 / 音质差怎么办？
  • 确认 TX 与 RX 电量充足，RX 已牢固插入手机接口。
  • 检查配对状态：TX / RX 指示灯应处于蓝色常亮（已连接）。未配对时，尝试把 TX 放回充电盒再取出重新配对。
  • 检查是否误触静音：静音时指示灯为红色常亮，双击按键解除。
  • 确认麦克风收音孔朝上、未被衣物或磁吸片遮挡。
  • 在 App 内调整增益电平与环境对应的降噪档位；环境安静时降噪开太强反而听感不自然，可调低档位。
声音断断续续 / 有干扰怎么办？
  • 确认在 200m（空旷可视距离）范围内，超距会断连。
  • 减少 TX 与 RX 之间的遮挡物（人体、墙面、金属）。
  • 远离强 2.4GHz 干扰源：Wi-Fi 路由器、无绳电话、蓝牙设备、其他无线麦。
  • 断连时通常可在指示灯快闪变化中观察到。
App 连不上设备怎么办？
  • 确认手机蓝牙已开启。
  • 重启 LarkSound / MOMA SOUND App 后重新连接。
  • 将 App 更新到最新版本。
  • 确认 TX 与 RX 已连接（蓝色常亮）后再打开 App 查看。
App 显示 MIC1 为静音（红色叉号），导致连不上 / 第二支麦连不上

此为用户区反馈的现象，官方文档未提供对应处理流程。官方 FAQ 明确的一项规则可用于自查：开启降噪时会优先显示降噪模式绿灯，而 MIC 识别开启后 TX1 才显示紫色、TX2 显示黄色——若 App 与实物指示灯状态不一致，多半是 App 内静音 / MIC 识别 / 指示灯开关三项设置互相覆盖所致。

建议排查顺序：先在 App 内关闭「指示灯开关」再看实体灯 → 检查是否处于静音（红灯常亮）→ 双击 TX 按键解除静音 → 仍无效则把全部 TX 放回充电盒重置后重新配对。

说明：本条依据说明书官方页面的用户问答区内容整理，非官方答复，仅供参考。

EQ 和混响分别适合什么场景？

EQ 调节：让声音更清晰自然，适合所有人声录制场景。

混响调节：让声音更饱满厚实。三档混响适用场景：

  • 小（Small）：语音聊天、录音、短视频
  • 中（Medium）：视频录制、播客
  • 大（Large）：直播唱歌
不接 RX 可以单独用麦克风吗？

LARK A1 是为手机直连设计的无线系统，官方说明书未提供脱离接收器独立录音的使用方式，实际使用需 RX 插入手机。

说明：本条依据说明书官方页面的用户问答区内容整理。

可以接电脑 / 相机使用吗？

Lightning 版 RX 官方文档明确说明不支持连接相机。官方商店的直播教程提到 USB-C 版 RX 可在电脑（Windows / macOS 声音设置）中被识别为输入设备，可用于 OBS 等直播软件；本机实测情况请以实际枚举结果为准。

说明：相机不支持为官方文档原文；电脑部分依据 Hollyland 官方商店博客的使用说明整理。

使用与保养建议
  • 充电：不用时将 TX 放回充电盒；定期为充电盒充电以保证随时可用。
  • 清洁：用柔软干燥的布擦拭 TX、RX 与充电盒，避免液体与磨料清洁剂。
  • 存放：放入附赠收纳袋，避免灰尘与物理损伤。
  • 电池保养：长期存放时确保充电盒与 TX 电量在 50% 左右，可延长电池寿命。
  • 麦克风位置：尽量靠近声源以获得最佳拾音效果。
